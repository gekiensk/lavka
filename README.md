# СанТех Лавка

Сайт-магазин сантехники в Тюмени: каталог с ценами и наличием, заказ без онлайн-оплаты, заявки «Перезвоните мне» и «Узнать наличие», информационные страницы, блог и админка с загрузкой товаров из Excel.

Стек: Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · PostgreSQL · Prisma 7.

## 1. Запуск на своём компьютере

Нужны [Node.js](https://nodejs.org) 20.9 или новее (лучше 22) и [Docker Desktop](https://www.docker.com/products/docker-desktop/) для базы данных.

```bash
git clone https://github.com/gekiensk/lavka.git
cd lavka
npm install                 # зависимости (+ генерация клиента Prisma)
cp .env.example .env        # настройки; значения по умолчанию подходят для локальной базы
docker compose up -d        # база PostgreSQL в Docker
npm run db:migrate          # создать таблицы
npm run db:seed             # тестовые данные: 4 раздела, 29 товаров, страницы, статьи
npm run dev                 # сайт на http://localhost:3000
```

Откройте http://localhost:3000 — магазин, http://localhost:3000/admin — админка (логин `admin`, пароль `admin12345`, создаётся тестовыми данными).

Остановить базу: `docker compose down` (данные сохранятся). Удалить базу вместе с данными: `docker compose down -v`.

> `npm run db:seed` можно запускать повторно: он **удаляет все товары и категории** и создаёт тестовые заново. Тексты страниц, настройки и баннеры, которые вы уже поменяли, не перезаписываются.

## 2. Админка

Адрес: `/admin`. Что там есть:

| Раздел | Что можно сделать |
|---|---|
| Сводка | новые заказы и заявки, быстрые ссылки |
| Заказы | список, смена статуса (новый → в работе → выполнен / отменён), комментарий менеджера |
| Заявки | «Перезвоните мне» и «Узнать наличие», отметка «обработано» |
| Товары | поиск, создание, редактирование, фото, характеристики, «С этим товаром покупают» |
| Категории | дерево разделов, фильтры по характеристикам для раздела, описание и SEO-поля |
| Импорт / экспорт | загрузка и выгрузка товаров в Excel или CSV (см. ниже) |
| Баннеры | слайдер на главной |
| Страницы | «О магазине», «Доставка и оплата», «Гарантия», политика и согласие на обработку данных |
| Статьи | блог |
| Настройки | город, адрес, часы работы, телефон, Telegram, email — они выводятся в шапке, подвале и контактах |

Тексты пишутся в формате Markdown — подсказка есть прямо под полем.

Создать администратора или сменить пароль из консоли:

```bash
npm run admin:create -- логин пароль       # пароль не короче 8 символов
```

Пароль текущего администратора также меняется в админке: «Настройки» → «Пароль администратора».

## 3. Загрузка товаров из Excel

Админка → **Импорт / экспорт**.

### Самый простой путь

1. Нажмите **«Все товары (.xlsx)»** — получите файл со всеми текущими товарами в нужном формате. Для пустого магазина скачайте **«Шаблон с инструкцией»**: в нём есть лист «Инструкция».
2. Правьте цены, наличие, добавляйте строки с новыми товарами в Excel.
3. Загрузите файл обратно, нажмите **«Проверить файл»**. Сайт покажет, сколько товаров будет создано и обновлено, какие появятся новые категории и в каких строках ошибки. **На этом шаге ничего не меняется.**
4. Если всё верно — **«Загрузить товары»**.

Форматы: `.xlsx` (Excel) и `.csv` (разделитель `;` или `,`, кодировка UTF-8 или Windows-1251 — определяется сама). Старый формат `.xls` не поддерживается: откройте его в Excel и сохраните как `.xlsx`. До 20 000 строк за раз.

### Колонки

Важен только **первый лист** и **первая строка с заголовками**. Порядок колонок любой, лишние колонки игнорируются (сайт покажет, какие не распознал).

| Колонка | Другие варианты названия | Что писать |
|---|---|---|
| **Артикул** (обязательно) | Код, Код товара, SKU | уникальный код товара — по нему сайт понимает, новый товар или существующий |
| Название | Наименование, Товар | нужно для нового товара |
| Категория | Раздел, Группа | путь через `/`: `Смесители / Для кухни`. Если такой нет — создастся |
| Бренд | Производитель, Марка | |
| Цена | Цена, руб; Розничная цена | `12500`, `12 500,00 ₽` — всё поймёт. Копейки округляются |
| Старая цена | Цена до скидки | заполните — товар попадёт в «Акции» со скидкой; пустая ячейка снимает скидку |
| Наличие | Остаток, Статус | `в наличии` / `под заказ`. Также понимает `да`, `нет`, `+`, `-`, число остатка (0 — под заказ) |
| Единица | Ед. изм. | `шт`, `м`, `компл` |
| Хит | Хит продаж | `да` / `нет` |
| Показывать | На сайте, Активен | `нет` — скрыть товар с сайта, не удаляя |
| Описание | | текст карточки товара |
| Фото | Изображения, Картинки | ссылки на фото через `\|`. Можно оставить пустым и загрузить фото в админке |
| Характеристика: Цвет | Х: Цвет | любые характеристики, по одной на колонку. Единица — после запятой: `Характеристика: Объём, л` |

### Правила

- Товар ищется по **артикулу**: есть — обновляется, нет — создаётся. Для нового товара обязательны название, категория и цена.
- **Пустая ячейка не стирает** значение у существующего товара. Исключения: «Старая цена» (пусто — скидка снимается) и характеристики (пусто — характеристика удаляется у товара).
- Режим **«Только цены и наличие»** меняет у существующих товаров цену, старую цену и наличие и больше ничего не трогает — удобно для ежедневного обновления из учётной программы. Новые товары в этом режиме не создаются.
- Строки с ошибками пропускаются, остальные загружаются. Номер строки в отчёте — как в Excel.
- Товары, которых нет в файле, **не удаляются**. Чтобы убрать товар с сайта, поставьте «Показывать: нет».
- Числовые характеристики (диаметр, объём, мощность) превращаются в фильтр «от — до» в каталоге. Чтобы характеристика появилась в фильтрах раздела, отметьте её в админке: «Категории» → раздел → «Фильтры на странице категории».

### Если у вас выгрузка из 1С или другой программы

Обычно достаточно переименовать заголовки колонок, как в таблице выше. Если формат сильно отличается — пришлите пример файла, сопоставление колонок легко дописать в `src/lib/import/columns.ts`.

## 4. Уведомления в Telegram и на почту

О каждом заказе и заявке приходит сообщение. Настройки — в файле `.env`. Если ничего не заполнить, заказы всё равно сохраняются и видны в админке.

**Telegram:**

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте имя — получите токен вида `123456:ABC...`. Это `TELEGRAM_BOT_TOKEN`.
2. Напишите своему боту любое сообщение (или добавьте бота в рабочую группу продавцов).
3. Узнайте chat_id: откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`. Для группы id начинается с минуса. Это `TELEGRAM_CHAT_ID`.

**Почта** (пример для Яндекса):

```
SMTP_HOST="smtp.yandex.ru"
SMTP_PORT="465"
SMTP_USER="info@ваш-домен.ru"
SMTP_PASSWORD="пароль приложения"     # id.yandex.ru → Безопасность → Пароли приложений
NOTIFY_EMAIL="куда-слать@ваш-домен.ru"
```

После изменения `.env` на сервере перезапустите сайт: `pm2 restart santeh-lavka`.

## 5. Размещение на VPS с доменом

Подойдёт любой VPS в России (Timeweb Cloud, Selectel, REG.RU, Beget и т. п.) с **Ubuntu 22.04 / 24.04**, от 1 ядра и **2 ГБ памяти** (сборке нужно ~1,5 ГБ). Ориентир по цене — 300–600 ₽/мес. Сервер в России упрощает соблюдение 152-ФЗ (данные покупателей хранятся в РФ).

Ниже — команды по шагам. Вместо `santeh-lavka.ru` подставьте свой домен.

### 5.1. Домен

В панели регистратора домена (REG.RU, nic.ru и т. п.) в разделе DNS создайте две записи:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | IP-адрес сервера |
| A | `www` | IP-адрес сервера |

Записи начинают работать через 15 минут – несколько часов.

### 5.2. Подготовка сервера

Подключитесь к серверу: `ssh root@IP-адрес`.

```bash
# Обновления и нужные программы
apt update && apt upgrade -y
apt install -y git nginx postgresql certbot python3-certbot-nginx ufw

# Node.js 22
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs
npm install -g pm2

# Файрвол: открыть только SSH и сайт
ufw allow OpenSSH && ufw allow 'Nginx Full' && ufw enable

# Если памяти 1–2 ГБ — файл подкачки, чтобы сборка не упала
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

### 5.3. База данных

```bash
# Придумайте свой пароль вместо СЛОЖНЫЙ_ПАРОЛЬ
sudo -u postgres psql -c "CREATE USER lavka WITH PASSWORD 'СЛОЖНЫЙ_ПАРОЛЬ';"
sudo -u postgres psql -c "CREATE DATABASE lavka OWNER lavka;"
```

PostgreSQL по умолчанию доступен только с самого сервера — так и должно быть.

### 5.4. Сайт

```bash
mkdir -p /var/www && cd /var/www
git clone https://github.com/gekiensk/lavka.git
cd lavka
cp .env.example .env
nano .env
```

В `.env` поменяйте:

```
DATABASE_URL="postgresql://lavka:СЛОЖНЫЙ_ПАРОЛЬ@localhost:5432/lavka?schema=public"
NEXT_PUBLIC_SITE_URL="https://santeh-lavka.ru"
SESSION_SECRET="..."          # результат команды: openssl rand -base64 32
```

и заполните Telegram и почту (раздел 4). Сохранить в nano: `Ctrl+O`, `Enter`, выйти: `Ctrl+X`.

```bash
npm ci                                       # зависимости
npm run db:deploy                            # создать таблицы
SEED_CONTENT_ONLY=1 npm run db:seed          # страницы, статьи, баннеры, настройки (без тестовых товаров)
npm run admin:create -- ваш_логин 'надёжный пароль'
npm run build                                # сборка (несколько минут)
pm2 start deploy/ecosystem.config.cjs        # запуск
pm2 save && pm2 startup                      # автозапуск после перезагрузки (выполните команду, которую покажет pm2)
```

Хотите сначала посмотреть сайт с тестовыми товарами — запустите `npm run db:seed` без `SEED_CONTENT_ONLY`. Но помните: он стирает весь каталог. После загрузки своих товаров используйте только вариант с `SEED_CONTENT_ONLY=1` или не запускайте вовсе.

Проверка: `curl -I http://127.0.0.1:3000` должен ответить `200`.

> `NEXT_PUBLIC_SITE_URL` подставляется в сайт при сборке. Если поменяли домен — заново `npm run build` и `pm2 restart santeh-lavka`.

### 5.5. nginx и HTTPS

```bash
cp deploy/nginx.conf /etc/nginx/sites-available/santeh-lavka
nano /etc/nginx/sites-available/santeh-lavka      # заменить santeh-lavka.ru на свой домен
ln -s /etc/nginx/sites-available/santeh-lavka /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

# Бесплатный сертификат Let's Encrypt (продлевается автоматически)
certbot --nginx -d santeh-lavka.ru -d www.santeh-lavka.ru --redirect
```

Готово — сайт открывается по `https://santeh-lavka.ru`.

### 5.6. Резервные копии

```bash
crontab -e
# добавьте строку — копия базы и фото каждую ночь в 3:00, хранятся последние 14:
0 3 * * * bash /var/www/lavka/deploy/backup.sh >> /var/log/lavka-backup.log 2>&1
```

Копии лежат в `~/backups`. Время от времени скачивайте их к себе: `scp -r root@IP-адрес:~/backups ./`.

Восстановление базы из копии:

```bash
pg_restore --clean --if-exists -d "postgresql://lavka:ПАРОЛЬ@localhost:5432/lavka" ~/backups/db_ДАТА.dump
```

### 5.7. Обновление сайта

Когда в репозитории появились изменения:

```bash
cd /var/www/lavka
git pull
npm ci
npm run db:deploy        # применит изменения базы, если они есть
npm run build
pm2 restart santeh-lavka
```

Логи сайта: `pm2 logs santeh-lavka`.

### 5.8. Поисковики

- [Яндекс Вебмастер](https://webmaster.yandex.ru) и [Google Search Console](https://search.google.com/search-console): добавьте сайт, подтвердите права, укажите карту сайта `https://santeh-lavka.ru/sitemap.xml`.
- Добавьте магазин в [Яндекс Бизнес](https://yandex.ru/sprav) и 2ГИС — для «сантехника рядом» это важнее всего.

## 6. А если Vercel?

Можно, но для этого магазина **рекомендуем VPS**:

- Vercel не хранит файлы: фото, загруженные через админку, пропадут. Придётся подключать внешнее хранилище (S3-совместимое: Yandex Object Storage, Selectel) и дорабатывать `src/lib/uploads.ts`.
- Базу нужно брать отдельно (Neon, Supabase и т. п.) — обычно за рубежом, что усложняет 152-ФЗ.
- Импорт большого Excel может упереться в лимит времени выполнения функций на бесплатном тарифе.

Если всё же Vercel: создайте базу PostgreSQL у провайдера, импортируйте репозиторий на vercel.com, в Settings → Environment Variables задайте те же переменные, что в `.env`, команду сборки `npx prisma migrate deploy && npm run build`, а домен подключите в Settings → Domains (Vercel покажет, какие DNS-записи добавить).

## 7. Перед запуском: чек-лист

- [ ] В админке → «Настройки»: настоящие адрес, телефон, часы работы, email, Telegram.
- [ ] «Страницы» → «Политика конфиденциальности» и «Согласие на обработку данных»: вписать ИП/ООО, ИНН, адрес, email вместо текста в `[квадратных скобках]`. Пройдитесь по остальным страницам — там тоже есть такие места (например, стоимость доставки).
- [ ] Подать уведомление об обработке персональных данных в Роскомнадзор (pd.rkn.gov.ru) — это обязанность по 152-ФЗ для всех, кто собирает телефоны покупателей.
- [ ] Загрузить свои товары и фото, проверить пару карточек.
- [ ] Заменить баннеры на главной.
- [ ] Если запускали полный `npm run db:seed` на сервере, смените пароль тестового администратора `admin` («Настройки» → «Пароль администратора»).
- [ ] Сделать тестовый заказ и убедиться, что пришло сообщение в Telegram и на почту.
- [ ] Заменить `public/og.png` (картинка для ссылок в соцсетях и мессенджерах, 1200×630) и `public/logo.png`, если появится фирменный логотип.

## 8. Для разработчика

### Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | режим разработки с автообновлением |
| `npm run build && npm start` | сборка и запуск как на сервере |
| `npm run lint` / `npm run typecheck` | проверка кода |
| `npm run db:migrate` | создать миграцию после правки `prisma/schema.prisma` и применить её |
| `npm run db:deploy` | применить готовые миграции (на сервере) |
| `npm run db:seed` | тестовые данные (`SEED_CONTENT_ONLY=1` — только тексты и настройки) |
| `npm run db:studio` | веб-интерфейс для просмотра базы |
| `npm run admin:create -- логин пароль` | создать администратора / сменить пароль |

### Где что лежит

```
prisma/schema.prisma          схема базы данных (с комментариями)
prisma/seed.ts                тестовые товары, категории, настройки магазина
prisma/seed-content.ts        тексты страниц, статьи, баннеры
src/app/(shop)/               страницы магазина
src/app/admin/                админка (вход, разделы, серверные действия)
src/app/sitemap.ts, robots.ts карта сайта и правила для поисковиков
src/components/               компоненты интерфейса
src/components/seo/JsonLd.tsx микроразметка Schema.org
src/lib/catalog.ts            запросы к каталогу: категории, фильтры, поиск
src/lib/import/               импорт и экспорт Excel/CSV
src/lib/notify.ts             уведомления в Telegram и на почту
src/lib/seo.ts                мета-теги и Open Graph для страниц
src/app/globals.css           фирменные цвета и общие стили
deploy/                       примеры настроек nginx, pm2 и скрипт резервных копий
```

### SEO

- Все страницы рендерятся на сервере, у каждой свои title, description, canonical и Open Graph.
- Адреса человекопонятные: `/catalog/smesiteli/dlya-kuhni`, `/product/smesitel-dlya-kuhni-grohe-eurosmart-33281003`.
- Микроразметка: `HardwareStore` (магазин, адрес, часы) на всех страницах, `Product` с ценой и наличием в карточке, `BreadcrumbList` в хлебных крошках, `Article` в блоге.
- `/sitemap.xml` собирается из базы: категории, товары, страницы, статьи. `/robots.txt` закрывает админку, корзину, оформление и поиск.
- Страницы каталога с фильтрами помечены `noindex`, чтобы не плодить дубли.
- Фото товаров автоматически сжимаются и отдаются в WebP нужного размера.
